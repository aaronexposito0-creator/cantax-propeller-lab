# Media provenance

Figures use actual project-generated CAD, saved MATLAB calculations and a fresh public-distribution baseline run. They do not depict validated flow fields or experimental measurements.

`excel-control.png`, `excel-rpm-1000.png` and `excel-results.png` are actual native Excel worksheet exports rasterized from PDFs. The parameter edit was performed/read back in an isolated copy: 900 to 1000 RPM. That edit capture itself does not imply a calculation rerun. Native exports use the Spanish Excel decimal separator; numeric inputs are locale independent.

`demo-results.gif` is a 45.5-second walkthrough of verified evidence, including the fresh 900-RPM public pipeline and historical change tests. It is explicitly labeled as saved outputs/document exports, not a live screen recording. See [PROVENANCE.json](PROVENANCE.json) and the [recording storyboard](../presentation/demo-storyboard.md).

CAD figures are renders of FreeCAD tessellations. Report previews are rasterizations of the included English PDF. No third-party illustration, stock render or invented result is included.
