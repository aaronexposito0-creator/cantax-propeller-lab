# Demonstration storyboard — 45 to 60 seconds

This plan uses real workbooks, generated geometry and calculated results. A saved-results GIF is a labeled visual walkthrough, not an application screen recording. No live recording should imply that a minutes-long calculation completed instantaneously.

## Recording sequence

| Time | Capture | On-screen caption or narration |
|---|---|---|
| 0–6 s | Open the real baseline Excel controller; show diameter, blade count, P/D and RPM inputs. | “One set of engineering inputs, a repeatable local workflow.” |
| 6–13 s | Change RPM from 900 to 1,000; save the workbook. Show the launcher command or menu selection. | “A speed change updates the operating case.” |
| 13–20 s | Record the actual launcher and a real completion result. Edit out the wait with an explicit time cut. | “Calculation time shortened in this video. New run, preserved inputs and outputs.” |
| 20–29 s | Open the generated FreeCAD geometry; compare the real baseline and five-blade geometries. | “Changing blade count and pitch regenerates the solid and downstream files.” |
| 29–40 s | Show the calculated comparison table and performance chart. | “900 to 1,000 RPM: 350.35 to 480.86 N; 1.278 to 1.887 kW. Calculated estimates.” |
| 40–48 s | Show the dynamics chart and the recorded motor-capacity limit. | “The higher-speed scenario exceeds the declared 25 N·m motor cap.” |
| 48–56 s | Open the actual PDF summary and its limitations page. | “Preliminary models, numerical verification and explicit limitations.” |
| 56–60 s | Repository title and real verified GitHub link. | “AI-assisted implementation. Author review before public communication. Not certified naval software.” |

## Required capture practice

Use a separate copy of the controller and a fresh run. Do not alter the preserved original examples. Close personal windows and use a neutral folder view. Crop personal paths, account identifiers and license dialogs; do not replace engineering figures with invented successful outcomes.

A real new run requires the licensed local engines and the documented setup. If recording only saved evidence, label the sequence “Saved verified results” and replace the parameter-change footage with the stored input/readback evidence. Do not animate an Excel cell edit and present it as a live application action.
